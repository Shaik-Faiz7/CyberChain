# CyberChain
CyberChain is a secure document management system that combines AES-256-GCM encryption, blockchain technology, and AI-powered classification to protect sensitive documents. The
system uses multi-factor authentication with email OTP, maintains an immutable audit trail through blockchain, and automatically classifies documents using Llama 3.1 and MiniLM models. It ensures data integrity, prevents unauthorized access, and provides complete transparency while maintaining user privacy through end-to-end encryption.

In the digital age, securing sensitive documents is critical as traditional storage systems face threats like unauthorized access, data breaches, and tampering. Organizations and individuals store important documents such as resumes, certificates, contracts, and identity proofs that require robust security measures. Existing solutions lack proper encryption, transparent audit trails, and intelligent classification capabilities.

CyberChain addresses these challenges by integrating military-grade encryption with blockchain’s immutability and artificial intelligence for automatic document categorization. This creates a comprehensive solution that not only secures documents but also organizes them intelligently while maintaining a tamper-proof history of all transactions.
